# Shop Stock Management in C++

A beginner-friendly C++ program that records item IDs, prices, and stock quantities, then displays each item's stock status.

## Stock Rules

- 5,000 to 10,000 units, inclusive: Enough stock
- Below 5,000 units: Limited stock; restocking is recommended

## How to Run

Compile and run `handling_shop_data_using_c++.cpp` using a C++ compiler. Enter the number of items, then provide each item's ID, price, and stock quantity.

## Language

C++
